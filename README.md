# STM32F1 Battery POC

STM32F1 based pcb to test 3s Li-ion cells protection with 3 phases brushless and steppers driver interfaces.

## IC List

- STM32F103C8T (Main MCU)
- QRE1113 (reflectance sensor)
- HT753-1 (3v3 LDO)
- LM78M (5v LDO)
- DRV8311 (BLDC driver)
- DRV8424 (Stepper driver)
- BQ77905 (3S battery protection)
- SN65HVD (CAN transceiver)
